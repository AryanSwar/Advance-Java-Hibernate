# Advance Java Hibernate Project

This repository contains a **Hibernate-based Java project** using **PostgreSQL** as the database.
It demonstrates how to use Hibernate ORM to perform database operations without writing raw SQL queries.

## Technologies Used
- Java
- Hibernate (ORM)
- PostgreSQL
- JDBC
- Maven / JAR-based setup
- Git & GitHub

## Features
- Hibernate configuration using `pom.xml`
- Entity-to-table mapping using annotations
- CRUD operations (Create, Read, Update, Delete)
- PostgreSQL database integration
- Session and Transaction management
- Exception handling

## Database Used
- **PostgreSQL**
