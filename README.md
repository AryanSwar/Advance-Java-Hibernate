# JDBC Project with PostgreSQL

This project demonstrates **Java Database Connectivity (JDBC)** using **PostgreSQL** as the backend database.  
It covers basic CRUD operations and shows how to connect a Java application to a PostgreSQL database.

## Features
- Connect to PostgreSQL using JDBC
- Perform **Create, Read, Update, Delete (CRUD)** operations
- Manage database connections, statements, and result sets
- Handle SQL exceptions and errors
- Example project can be adapted for any relational database

## Skills Covered
- JDBC API in Java
- PostgreSQL database operations
- SQL query execution in Java
- Exception handling
- Version control using Git
